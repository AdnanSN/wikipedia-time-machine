# Weekly self-assessment

The team guide asks every contributor to report, each week: work done, hours spent, links to the commits or pull requests that show it, the plan for next week, AI tools used, and anything else (notes, blockers). We keep one file per week, named after its Monday, and bring it to the weekly meeting.

Each person fills in their own section, in a pull request (it can be the same pull request as their week's work). The links must match the git history: the supervisor checks.

Copy this for a new week:

```markdown
# Week of <Monday's date>

## <Name>

- **Work done:**
- **Hours:**
- **Evidence:** <links to commits and pull requests>
- **Plan for next week:**
- **AI tools used:** <tool and model, and the docs/AI_USE.md rows>
- **Notes and blockers:**
```
