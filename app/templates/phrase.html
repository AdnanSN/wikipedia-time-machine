The history is rows, so a window function can walk it. For each version: does it contain the phrase, and did the one before? The versions where the two answers differ are the edits that put the phrase in or took it out.

SELECT row_start, rev_id, editor, has_phrase
FROM (SELECT row_start, rev_id, editor,
             content LIKE '%...%' AS has_phrase,
             LAG(content LIKE '%...%') OVER (ORDER BY row_start) AS had_phrase
      FROM article FOR SYSTEM_TIME ALL
      WHERE page_id = {{ page_id }}) AS version
WHERE has_phrase <> COALESCE(had_phrase, 0);
